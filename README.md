# 在线学习平台

在线学习平台是一个综合性的教育平台，支持学员在线学习课程、参与测评考试，讲师创建和管理课程内容，以及用户之间的交流互动。

## 项目结构

```
.
├── backend                 # 后端服务
│   ├── src                 # 后端源代码
│   │   ├── main            # 主要代码
│   │   │   ├── java        # Java源代码
│   │   │   │   └── com/spm5/olp          # 主包
│   │   │   │       ├── config            # 配置类
│   │   │   │       ├── controller         # 控制器层
│   │   │   │       ├── entity            # 实体类
│   │   │   │       ├── mapper            # MyBatis Plus映射器
│   │   │   │       ├── service           # 服务层
│   │   │   │       │   └── impl          # 服务实现类
│   │   │   │       └── utils             # 工具类
│   │   │   └── resources                 # 资源文件
│   │   │       ├── mapper                # MyBatis XML映射文件
│   │   │       └── application.yml # 应用配置文件
│   │   └── test            # 测试代码
│   └── pom.xml             # Maven配置文件
└── frontend                # 前端应用
    ├── src                 # 前端源代码
    │   ├── assets          # 静态资源
    │   ├── components      # Vue组件
    │   ├── views           # 页面视图
    │   ├── router          # 路由配置
    │   ├── stores          # 状态管理
    │   └── types           # TypeScript类型定义
    ├── package.json        # npm配置文件
    └── vite.config.ts      # Vite配置文件
```

## 技术架构

### 后端技术栈
- **Spring Boot 3.0.0**: 用于快速构建Java应用程序
- **Java 17**: 后端编程语言
- **MyBatis Plus 3.5.5**: 数据持久层框架，增强MyBatis功能
- **Spring Security**: 安全认证和授权框架
- **Spring Validation**: 数据验证框架
- **MySQL**: 关系型数据库
- **Maven**: 项目构建和依赖管理工具
- **Lombok**: 简化Java代码编写的工具库

### 前端技术栈
- **Vue 3**: 渐进式JavaScript框架
- **TypeScript**: JavaScript的超集，提供类型安全
- **Vite**: 新一代前端构建工具
- **Vue Router**: Vue.js官方路由管理器
- **Pinia**: Vue.js的状态管理库
- **ESLint**: JavaScript/TypeScript代码质量检查工具

## 系统设计方案

### 1. 整体架构模式
采用前后端分离架构：
- 前端通过RESTful API与后端通信
- 后端提供统一的数据接口和业务逻辑处理
- 前端负责页面渲染和用户交互

### 2. 后端模块划分

#### 核心模块
1. **用户管理模块**
   - 用户注册、登录、权限认证
   - 用户信息管理
   - 角色权限控制（学员、讲师、管理员）

2. **课程管理模块**
   - 课程创建、编辑、发布、下架
   - 课程分类管理
   - 课程内容存储与访问控制

3. **学习进度模块**
   - 学习记录追踪
   - 学习进度同步
   - 笔记管理

4. **测评考试模块**
   - 题库管理
   - 在线考试系统
   - 自动阅卷与成绩统计

5. **交流互动模块**
   - 社区讨论
   - 私信功能
   - 消息通知系统

6. **资源管理模块**
   - 学习资源上传与分类
   - 资源预览与下载
   - 资源权限控制

#### 技术实现要点
- 使用Spring Security实现JWT Token认证
- 使用MyBatis Plus进行数据库操作，提高开发效率
- 使用MySQL存储结构化数据
- 实现统一异常处理和参数校验
- 使用Lombok简化实体类代码

### 3. 前端模块划分

#### 核心功能页面
1. **公共页面**
   - 登录/注册页面
   - 首页导航
   - 用户个人中心

2. **学员功能页面**
   - 课程浏览与学习页面
   - 在线考试页面
   - 学习报告页面
   - 消息通知页面

3. **讲师功能页面**
   - 课程管理页面
   - 题库管理页面
   - 学生成绩分析页面
   - 数据统计页面

4. **交流社区页面**
   - 讨论区
   - 私信聊天界面

#### 技术实现要点
- 使用Vue 3 Composition API组织代码
- 使用Vue Router实现单页应用路由管理
- 使用Pinia进行全局状态管理
- 实现响应式布局适配不同设备
- 组件化开发提高代码复用性

## 开发环境搭建

### 后端环境要求
- Java 17+
- MySQL 8.0+
- Maven 3.8+

### 前端环境要求
- Node.js 20.19.0+ 或 22.12.0+
- npm 或 yarn 包管理器

## 快速开始

### 后端启动步骤
1. 创建MySQL数据库
2. 修改`application.properties`配置数据库连接
3. 执行以下命令启动服务：
```bash
cd backend
./mvnw spring-boot:run
```

### 前端启动步骤
1. 安装依赖：
```bash
cd frontend
npm install
```
2. 启动开发服务器：
```bash
npm run dev
```

## 部署方案

### 生产环境部署
- 后端：打包为jar文件，通过Java命令运行或部署到应用服务器
- 前端：构建生产版本，部署到Nginx或CDN
- 数据库：使用云数据库服务或独立部署MySQL
